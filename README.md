# Connected components labeling on PYNQ-Z1
Project for the UTCN CTI third year Computer Systems Structure course.

Labeling different connected components of objects in images, running on the PYNQ-Z1 SoC, with FPGA hardware acceleration.
~211 faster on the first algorithm pass than the Python equivalent.
